# 🎓 StudyVault

### All Tools. One Place. Built for Students.

StudyVault is a modern **offline student productivity toolkit** that brings useful PDF, image, file-management, and academic utilities into one clean workspace.

It is designed with **privacy, simplicity, and offline usage** in mind.

> 🔒 Your files stay on your device.  
> No uploads. No accounts. No cloud processing.

---

## ✨ Overview

Students often need different websites or applications for simple tasks such as:

- Editing PDFs
- Compressing images
- Renaming files
- Calculating percentages
- Calculating GPA
- Organizing study files

StudyVault brings these tools together into **one searchable offline toolkit**.

Everything runs directly inside your browser.

---

## 🚀 Features

### 📄 PDF Editor

A dedicated workspace for common PDF operations.

Features include:

- Merge PDF files
- Split PDFs
- Reorder pages
- Remove pages
- Compress PDFs
- Convert PDFs
- Extract text
- Manage PDF files from one workspace

---

### 🖼️ Photo Editor

A simple image workspace for quick editing.

Features include:

- Rotate images
- Flip images
- Crop images
- Resize images
- Compress images
- Convert image formats
- Export edited images

---

### 📁 File Tools

Useful tools for managing files directly inside the browser.

Features include:

- Rename files
- Check file size
- Detect file type
- Find duplicate files
- Batch file operations
- View useful file information
- Export processed files
